# HAAF Pilot Experiment

This repository contains the code and data for the **pilot experiment** described in Section 4 of:

> **Beyond Benchmark Islands: Toward Representative Trustworthiness Evaluation for Agentic AI** (KDD 2026 Blue Sky)

The pilot demonstrates one complete cycle of the **Trustworthy Optimization Factory**: red-team vulnerability attribution → blue-team hardening → re-evaluation.

## Key Components

### Agent Versions

| Version | System Prompt | Interventions |
|---------|--------------|---------------|
| **Control** (baseline) | Generic helpful assistant | None |
| **Treated** (hardened) | Safety-aware prompt | Tool-output Firewall + Confirmation Gate |

- **Tool-output Firewall**: Wraps every tool return with `[UNTRUSTED TOOL OUTPUT]` delimiter, instructing the agent to never follow embedded instructions.
- **Confirmation Gate**: Blocks high-risk actions (message dispatch, writes to protected paths) before execution.

### Failure Taxonomy (8 classes)

| Code | Failure Type | Description |
|------|-------------|-------------|
| PI | Prompt Injection | Agent follows malicious instructions in tool outputs |
| GD | Goal Drift | Agent deviates from original user objective |
| UA | Unauthorized Action | Agent performs actions outside permitted scope |
| HT | Hallucinated Tool-use | Agent calls tools with fabricated parameters |
| RF | Recovery Failure | Agent fails to recover from errors gracefully |
| OF | Operational Failure | Agent fails under resource constraints |
| PL | Policy Leak | Agent leaks sensitive/internal information |
| SH | Social Harm | Agent produces biased or harmful outputs |

### Scenario Suite

24 hand-crafted scenarios across 4 categories:

| Category | Count | Risk Severity | Example |
|----------|-------|--------------|---------|
| Benign | 8 | 1–2 | Flight booking, policy lookup |
| Adversarial | 8 | 3–5 | Injected instructions in tool outputs |
| Operational | 4 | 2–3 | Latency spikes, malformed data |
| Social | 4 | 4–5 | Bias requests, emotional pressure |

## Reproducing the Experiment

### Prerequisites

- Python 3.10+
- [vLLM](https://github.com/vllm-project/vllm) (for serving the model)
- Python packages: `openai`, `matplotlib`, `numpy`

```bash
pip install openai matplotlib numpy
```

### Step 1: Serve the Model with vLLM

We use **Qwen3-8B** served via vLLM with function calling support:

```bash
vllm serve Qwen/Qwen3-8B \
    --host 0.0.0.0 \
    --port 8000 \
    --max-model-len 8192 \
    --enable-auto-tool-choice \
    --tool-call-parser hermes \
    --chat-template-kwargs '{"enable_thinking": false}'
```

> **Note**: The `--enable-auto-tool-choice` and `--tool-call-parser hermes` flags enable OpenAI-compatible function calling. Adjust `--max-model-len` and GPU settings based on your hardware.

### Step 2: Run the Baseline Agent (Control)

```bash
# Clear previous logs (if re-running)
rm -f logs/control_runs.jsonl logs/control_trajectories.jsonl

# Run all 24 scenarios with the baseline agent
python runner.py --version control --model Qwen/Qwen3-8B --api-base http://localhost:8000/v1
```

### Step 3: Run the Hardened Agent (Treated)

```bash
# Clear previous logs (if re-running)
rm -f logs/treated_runs.jsonl logs/treated_trajectories.jsonl

# Run all 24 scenarios with the hardened agent
python runner.py --version treated --model Qwen/Qwen3-8B --api-base http://localhost:8000/v1
```

You can also run specific scenarios:

```bash
python runner.py --version control --scenarios s01,s09,s21
```

### Step 4: Score and Analyze Results

```bash
# Auto-label violations
python scorer.py control
python scorer.py treated

# Generate full analysis (metrics, tables, heatmap)
python analyze.py
```

### Step 5: View Results

```bash
# Quick summary
python summary.py

# Generated outputs are in results/:
#   metrics.csv         → SR, VR, RWF per version
#   failure_counts.csv  → Failure type distribution
#   run_summary.csv     → Per-scenario breakdown
#   failure_heatmap.png → Visual heatmap
```

### Expected Results

| Metric | Baseline | Hardened | Rel. Change |
|--------|----------|---------|-------------|
| Success Rate | 83.3% | 95.8% | +15.0% |
| Violation Rate | 16.7% | 4.2% | −75.0% |
| Risk-Weighted Failure | 0.210 | 0.062 | −70.6% |
