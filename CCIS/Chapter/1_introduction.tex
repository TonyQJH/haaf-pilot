\section{Introduction}
\label{sec:introduction}

Agentic AI systems are evolving from passive assistants into autonomous decision-makers that plan, call tools, and act on retrieved data~\cite{mialon2023gaia,drouin2024workarena,xie2024osworld,xi2024agentir}. Their failures extend beyond incorrect answers to goal drift, unsafe tool use, and socially harmful behaviour: a recent coding agent deleted a production database under an explicit code freeze~\cite{nolan2025replit}, and indirect prompt injection through retrieved documents silently redirects tool-augmented agents~\cite{greshake2023indirect,zhou2024poisonedrag}. Trustworthiness is a deployment-level concern shaped by realistic environmental, operational, and social conditions.

Current evaluation is limited in two compounding ways. First, ``trustworthiness'' is used inconsistently---as safety, helpfulness, or umbrella; existing surveys list many desiderata~\cite{liu2024trustllm,wang2024trustworthyagent} but offer no small measurable property set. Second, existing benchmarks focus on isolated slices (task-solving~\cite{zhou2023webarena}, coding~\cite{jimenez2023swebench}, hallucination~\cite{li2023halueval}, jailbreak resistance~\cite{chao2024jailbreakbench}, tool use~\cite{li2023apibank}) constructed around narrow tasks and single failure modes~\cite{liang2023helm,kiela2021dynabench}, so high scores do not imply real-world reliability. The central limitation is the lack of \emph{both} a concrete trustworthiness definition and a principled notion of \emph{representativeness}: trustworthiness is distributional, and benchmark--deployment misalignment creates false confidence~\cite{koh2021wilds,shirali2022dynamicbench} on low-frequency high-consequence events.

We propose the \textbf{Holographic Agent Assessment Framework (HAAF)}. The key idea is to first \emph{define} trustworthiness as a five-property profile (P1--P5, \S\ref{subsec:defining_trustworthiness}) and then \emph{measure} it over a \emph{scenario manifold} spanning task types, tool interfaces, interaction dynamics, social contexts, and risk levels. A distribution-aware representative sampling engine defines \emph{what} to test; three probing interfaces (static analysis, interactive sandbox simulation, social-ethical alignment) define \emph{how}; the v1 instantiation exercises the sandbox layer in depth, with the others reserved for future cycles. Components are connected through an iterative \emph{Trustworthy Optimization Factory}: red-team probing exposes vulnerabilities, blue-team hardening designs interventions, re-evaluation verifies improvement. We assess \emph{deployed agentic systems} (model + prompts + tools + guardrails + oversight) rather than weights in isolation.

\paragraph{Representativeness: target vs.\ current evidence.}
The 100 hand-authored scenarios split into 24 design-study cases driving the focal Factory cycle and 76 validation cases instantiating the five-property profile. The five sandbox tools (\texttt{search\_docs}, \texttt{db\_query}, \texttt{read\_file}, \texttt{write\_file}, \texttt{send\_message}) each map to a top-$K$ operation class in public agent benchmarks~\cite{jimenez2023swebench,li2023apibank,zhou2023webarena,liu2023agentbench}. We claim the \emph{target} and the \emph{methodology} (Layer-4 objective with a deployment-grounded weighting hook), not that the present scenarios constitute a statistically representative slice of production traffic; grounding weights in real telemetry is v2 (\S\ref{sec:conclusion}).

\paragraph{Contributions.}
\begin{enumerate}[leftmargin=*,label=(C\arabic*)]
\item \textbf{Definition.} A five-property operational definition (P1--P5) grounded in current risk frameworks~\cite{nist2023airmf,eu2024aiact}, with \emph{Improper Refusal} (IR) as a first-class taxonomy class mapped to P1.
\item \textbf{Cross-model evaluation.} 13 models across seven families (Llama, Mistral, Kimi, GLM, Qwen, GPT-oss, DeepSeek) on a 100-scenario suite, producing $2{,}600$ Control/Treated trajectories.
\item \textbf{End-to-end instantiation.} A shared sandbox with red-team attribution, blue-team interventions, and re-evaluation: 12 of 13 systems improve on $\mathrm{RWF}$ without per-model tuning; Qwen3-32B is intervention-resistant ($\Delta{=}+0.019$).
\item \textbf{Layer-4 reference implementation.} A reference implementation of the sampling objective; a 40-of-100 subset preserves the cross-model ranking (Kendall-$\tau$\,=\,0.890, Spearman-$\rho$\,=\,0.963).
\item \textbf{Statistical confidence.} Wilson 95\% CIs and a paired-scenario bootstrap ($B{=}10{,}000$) on four anti-scaling pairs; two reject at $p<0.05$, a third at the boundary ($p=0.050$). With $n{=}14$--$26$ per property, per-cell CIs span $\pm 0.2$---descriptive, not powered (\S\ref{sec:discussion}).
\item \textbf{Explicit scope.} Scenarios and tools are hand-authored; IR validation uses a single LLM-judge (Kimi-K2.5, itself one of the 13 evaluated agents---a deliberate scope limitation in \S\ref{sec:discussion}); a deployment-grounded sampler is committed as v2.
\end{enumerate}
